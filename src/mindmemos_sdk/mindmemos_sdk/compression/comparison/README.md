# 31 项任务：Baseline 1、Baseline 2 与 ADyn 对比

三组比较使用同一份[31 项任务列表](../task_list_31.md)，范围为我们的方法实验中触发并实际应用压缩的任务。主模型均为 GPT-5.5，评分模型为 GPT-5.4；Baseline 2 和我们的方法均使用 Qwen3.5-122B-A10B、`reasoning={"effort":"high"}` 作为压缩器。下表汇总已完成的实验结果，不是本次发布时重新运行的成绩。

| 类别 | 指标 | Baseline 1：无压缩 | Baseline 2：16,384 阈值同步全量压缩 | 我们：动态阈值异步压缩（ADyn） |
|---|---|---:|---:|---:|
| 性能 | 平均分 | 72.79 | 63.89 | 71.74 |
| Agent | 输入 token | 20,841,560 | 22,284,241 | 13,867,209 |
| Agent | 输出 token | 305,067 | 482,127 | 328,282 |
| Agent | 总 token | 21,146,627 | 22,766,368 | 14,195,491 |
| Agent | 费用 | $32.2913 | $42.0954 | $25.4138 |
| Agent | 请求次数（实际使用） | 799 | 1171 | 754 |
| Agent | 累计任务耗时 | 149.96 分钟 | 243.38 分钟 | 158.43 分钟 |
| Agent | 平均任务输入峰值 | 39,063 | 34,750 | 28,786 |
| Compressor | 输入 token | — | 965,786 | 1,072,353 |
| Compressor | 输出 token | — | 190,607 | 113,530 |
| Compressor | 总 token | — | 1,156,393 | 1,185,883 |
| Compressor | 费用 | — | $0.6476 | $0.5784 |
| Compressor | 调用 / 实际应用次数 | — | 104 / 104 | 78 / 63 |
| Compressor | 累计请求耗时（已应用） | — | 35.75 分钟 | 17.90 分钟 |
| 合计 | 总 token | 21,146,627 | 23,922,761 | 15,381,374 |
| 合计 | 费用 | $32.2913 | $42.7430 | $25.9921 |

统计口径：

- token、费用及 Agent 请求次数只统计实际进入轨迹的主模型响应和实际应用的摘要；不计未使用请求、评分及辅助调用。费用采用 API 回执中的美元金额，代表已使用响应的费用，不是完整账户账单。
- 压缩器“调用 / 实际应用次数”同时保留已发出请求数与应用数；其 token、费用和累计请求耗时仅计已应用部分。
- 累计任务耗时为 31 项任务执行时间之和，包含工具执行；平均任务输入峰值为各任务已使用主请求的最大 API 输入 token 的算术平均。异步压缩与 Agent 执行重叠，二者耗时不直接相加。
- Baseline 1 保留宿主默认 compaction，这 31 项没有实际应用原生摘要；Baseline 2 的 16,384 是可压缩历史的估算门槛，不是主模型输入硬上限。ADyn 的增量门槛下限为 8,192，全量门槛动态计算，见 [Agent 复现说明](../agent/README.md)。
